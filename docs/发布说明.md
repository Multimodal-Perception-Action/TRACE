# 开源候选版与 ModelScope 分发

这是从工程版独立整理的新目录，没有复制私有仓库历史。项目自有代码、发布权重及最小推理资源采用 Apache-2.0，第三方组件保留原许可证。负责人已确认权重和生成示例可以公开分发；原始训练数据不在本次发布范围内。

## 论文与示例

TRACE: Typed Reference-Aware Conversational Editing for Humanoid Motion Diffusion。

README 包含论文简介、现有方法图与走路、挥手、开合跳三个 MP4 示例。当前开源包覆盖生成推理链路，未包含论文独立编辑器及训练流水线。视频使用首尾站立、平滑及前后掌四点后处理，为运动学演示，不作为论文原始评估结果或真机执行保证。

## 分成三部分

1. **代码目录**：文本到动作、首尾站立、前后掌四点联合修复、SPS、渲染、安装脚本和测试。README 为英文，新增发布工具和注释为英文；既有算法源码保留中文说明。
2. **`publish/model/`**：两个扩散推理权重及 LLM LoRA，约 0.53 GB。Qwen 两个大基座由使用者从官方 ModelScope 下载，不重复上传。
3. **`publish/data/`**：仅推理需要的归一化统计、解析构造的站姿、三条新写的提示词。没有 BONES-SEED 训练/测试动作、caption、Plan 缓存，也没有私有视频。

模型和数据上传目录均由 Git 忽略。`release_manifest.json` 给出每个文件的哈希及下载后的目标位置，代码与权重可以分开分发。

## 发布位置

- 代码：https://github.com/Multimodal-Perception-Action/TRACE
- 模型：https://modelscope.cn/models/kangzejian/TRACE
- 最小推理资源：https://modelscope.cn/datasets/kangzejian/TRACE-Inference-Assets

上传脚本默认仅预览，实际执行需 `--execute` 和发布审批状态为真。新建 ModelScope 仓库默认为私有，验证后公开。模型仓库可用性以实际上传后的检查为准。私有工程不被修改。

## 安装和运行

```bash
TRACE_PYTHON=python3.10 bash install.sh
.venv/bin/python tools/hub_assets.py download --model-repo kangzejian/TRACE --data-repo kangzejian/TRACE-Inference-Assets
bash run.sh --text "A person walks forward at a steady pace." --output outputs/walk
```

输出使用 `motion_final.sps`，网页与视频渲染的是修复后的动作。环境安装与权重下载分开；仅复制代码也可先运行不依赖模型的测试。
